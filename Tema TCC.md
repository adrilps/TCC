# LOL



trabalho de análise de dados históricos de partidas do video game league of legends para melhora de desempenho de jogadores através de escolhas que levam a maior taxa de vitórias



\- trabalho de análise de dados históricos de partidas: análise dos dados de partidas já realizadas por diversos jogadores para determinação de escolhas que levaram a uma vitória



\- para melhora de desempenho de jogadores: disponibilização dos dados das escolhas detectadas no passo anterior para o jogador.



\- através de escolhas que levam a maior taxa de vitórias: a diferença entra a taxa de vitória de decisões ruins e boas







Resumo: 



&#x09;o estudo de dados de partidas históricas de diversos jogadores do jogo league of legends e das decisões que levam a vitórias mais frequentemente a partir de arquivos de replay com objetivo de disponibilizar estatísticas a jogadores que desejam melhorar suas estratégias.

Novo Resumo: 

&#x09;

&#x09;1 - Jogos eletrônicos cresceram em popularidade nos últimos 30 anos.

&#x09;1 - Dentre esses jogos populares, League of Legends é um exemplo. O jogo competitivo de estratégia em equipe conta com XX milhões de usuários, e obter o maior ranque é algo desejável.

&#x09;2 - Para alcançar a vitória os jogadores podem optar por diversas estratégias, porém avaliar o potencial de cada uma delas pode ser empiricamente complexo.

&#x09;3 - Esse trabalho tem como objetivo avaliar as decisões dos jogadores que levaram ao maior conjunto de vitórias.

&#x09;4 - Para isso serão levantados dados de diversos jogadores em um determinado período de tempo e uma determinada região geográfica, para a análise das escolhas que levaram a um maior número de vitórias.
